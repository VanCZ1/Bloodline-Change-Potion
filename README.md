# Bloodline-Change-Potion

4 new potions have been added to Skyrim, allowing players to change their bloodline to human, werewolf, vampire, or vampire lord.

## Requirements

- [pyro](https://github.com/fireundubh/pyro/releases)
  - Add to your `PATH`.
- [Creation Kit](https://store.steampowered.com/app/1946180/Skyrim_Special_Edition_Creation_Kit/)
  - Extract `Scripts.zip`.
  - Set path in `build.ppj`.

## User Requirements
- [Skyrim Script Extender](https://www.nexusmods.com/skyrimspecialedition/mods/30379)
	- Any version.

## Building

```
git clone https://github.com/VanCZ1/Bloodline-Change-Potion.git
cd Bloodline-Change-Potion
pyro build.ppj --no-implicit-imports
```
